# Journal of Modern Optics candidate study resources

These materials correspond to the working paper **Response Compressibility and Accuracy-Dependent Learning Requirements for Multilayer Optical Surrogates**. This is a **candidate analysis, not a complete reproduction deposit**. The study source, available fit records, compact tables, and figures are provided; its full response arrays and some source-design archives are still absent.

## Numerical definition

The Python transfer-matrix calculation uses nominal εᵣ(SiO₂) = 2.1316, εᵣ(TiO₂) = 5.913, μᵣ = 1, zero conductivity, normal incidence, and 200 equally spaced frequencies from 250 to 1050 THz. The response is field-coefficient magnitude `|t|`. The inherited propagation applies N−1 of N stored thicknesses, takes material N as the exit medium, and leaves the last thickness inactive. The model is nondispersive and does **not** predict finite-stack power transmission into air. The 350–750 THz window is a separate spectral sensitivity test, not 350–750 nm.

## Available material

- `source/` is the exact small source snapshot supplied for this analysis. Its generator SHA-256 is `c2504884553ccf4674b4468334bb78f962254d22523d6e5cf5885cacb374beee`, matching the material-model manifest. The source README records the numerical-model change and its limitations. Run its commands from inside `source/`; source-code identity does not by itself establish that all archived arrays are here.
- `records/primary_learning_curves.csv` contains 72 consolidated primary-grid mean rows. `records/primary_thresholds.csv` extracts first tested thresholds. Both use batch 1,024 in the low-sample and 5k–40k portions; the twelve repeated 5k scores match per seed. The older batch-512 low-sample run is retained **inside** `run_records_review.zip` for provenance, but its rows are excluded from these paper tables. The matching command is in `tools/run_low_sample_matched.sh`; run it with the `source/` project path and a fresh results directory.
- The other compact files under `records/` include PCA/AE, capacity, forward-model, 20-layer extended, spectral, and 14/16/18-layer training-extension summaries and selected individual fit scores. For 14, 16, and 18 layers the paper's **final capacity endpoints come from `records/capacity/capacity_diagnostic_decision.csv`**, not the preliminary parameter columns of `records/intrinsic/paper1_master_summary.csv`. `records/run_records_review.zip` preserves full available run histories from the review bundle (SHA-256 `f34f73d6fe1285259508fc3079c091b123e8cf5002d5a07dcbffd25b68163c12`); `records/matched_low_sample_records.zip` preserves the matching batch-1,024 refinement (SHA-256 `dd3cca7191a88fb2a523648b4b51d2d81edfd69d57851447e2f5089eca89387b`). Both are **fit-record archives, not raw-response archives**.
- `figures/Figure_01.png` through `Figure_06.png` correspond to the working manuscript. Figure 2 plots six observed capacity crossings; the 20-layer capacity threshold was not reached, so it is not plotted as a measured point.

The two spectral design-source ensembles used in the crossed-grid study are labeled A and B in the Supporting Information. Their source-archive SHA-256 values are `4ae7d4f906a62b1a2a25e42dbabaec1f31df293dbe9bcecb540afc88292886c9` and `019e13aa1db80110c498aafee9f0bcb2a752f6e0ce71753fa225fbe74b8f540a`. Both ensembles' responses were calculated under the numerical definition above; no old response-label comparison is part of the candidate result.

The material manifest records expected ZIP SHA-256 values `019e13aa1db80110c498aafee9f0bcb2a752f6e0ce71753fa225fbe74b8f540a` and `244ed6661af15e6f5dca5d509082869f78fe90f951adc1691399dec8a0f6ca71`, respectively. The compressed primary design matrix already present under `data/exact_designs/` is not a substitute for these responses.
2. Publish the additional 14-, 16-, and 18-layer 160,000-pair training matrices and their source-design archive, identified in `records/extension_data/generation_manifest.json`. These response matrices are not in `run_records_review.zip`.
3. Publish the A-ensemble 20-layer source designs and both spectral-window response arrays (or validated instructions sufficient to reconstruct their exact recorded bytes), along with a complete validation report.
4. Verify public downloads, checksums, file names, and a clean rerun of the analysis commands. Replace the manuscript's bracketed data-availability placeholders only after this verification. The older [v1.1.0 data assets](https://github.com/mjavani54/nanophotonic-response-manifold-learning-resources/releases/tag/v1.1.0) contain another response model and cannot stand in for the absent current arrays.

Run `python studies/jmo_2026_candidate/verify_summary.py` from the repository root for a **summary-level** check. No repository check here purports to reconstruct the neural fits without the absent raw arrays and compute environment.

# Release notes

## v1.0.0 — 2026-08-24

Initial GitHub-ready reproducibility package for the ACS Photonics manuscript.

Included:

- latest human-revised manuscript draft;
- six final/diagnostic Python analysis scripts;
- frozen manuscript-level CSV results;
- six final figures plus ACS Table of Contents graphic;
- data manifest and external-data release instructions;
- methods-source note derived from the dissertation;
- reproducibility workflow and result provenance;
- GitHub website upload instructions;
- citation, license, environment, and integrity metadata.

Raw simulation datasets and large intermediate run archives are excluded because of size.

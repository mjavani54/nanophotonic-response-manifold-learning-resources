# Release notes

## Working version 1.1.0 (not tagged or released)

- Added an archived MATLAB reference implementation and a later Python reconstruction of the documented response convention. The original Python program used for data generation has not been identified in the public repository.
- Added exact compressed design matrices for all reported 50k ensembles and the 20-layer 200k ensemble.
- Added response-label validation fixtures and an automated generator check.
- Documented the planned release assets containing the exact archived response CSVs. They have not yet been attached to a GitHub release.
- Added explicit provenance documentation for the historical 250–1050 THz, `abs(t_legacy)` label definition and the unused final sampled thickness.
- The manuscript file was removed from this repository; the revised manuscript and Supporting Information are maintained as separate submission files.

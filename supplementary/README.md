# Supporting Information

The ACS Photonics Article, **Response Complexity and Accuracy-Dependent Learning Resources in Multilayer Nanophotonic Surrogate Models**, is accompanied by a separate Supporting Information document. It reports the primary response and learning-curve tables, exact rank-permutation reanalysis, accuracy-threshold and layer-count comparisons, a fixed-design spectral-window experiment (Table S8), and training-only augmented-cohort results (Table S9).

The submission also includes four ZIP archives:

- `ACS_Photonics_Summary_Reanalysis.zip`: class-summary inputs, executable reanalysis, and numerical outputs.
- `ACS_Photonics_20L_Window_Sensitivity_Resources.zip`: historical 20-layer inputs, code, all 48 autoencoder records, summaries, and checksums.
- `Table2_Extended_Data_and_Run_Package.zip`: generated training matrices, generation and training scripts, and source checks.
- `ACS_Photonics_Table2_Extended_Results.zip`: individual augmented-fit scores, optimization histories, metadata, and audits.

These new resources are separate from the frozen v1.1.0 repository release. The exact archived primary design and response CSVs are public as that release's two data assets. The four new ZIP archives must be made available to reviewers with the Article; merely updating this README does not make them public.

# Supporting Information scope

The current working paper is **Response Compressibility and Accuracy-Dependent Learning Requirements for Multilayer Optical Surrogates**. Its separate Supporting Information reports the model convention, nine tables (S1–S9), the 72-row primary learning grid, rank tests, layer-count baseline, censoring sensitivity, two-ensemble spectral-window test (48 fits), and 14/16/18-layer training extensions (72 fits).

Candidate-study code, figures, compact tables, and recorded fit outputs are under [`studies/jmo_2026_candidate/`](../studies/jmo_2026_candidate/README.md). Exact present-study response matrices and some source-design archives are **not yet public in this repository**. The prior ACS submission archives and the old v1.1.0 response files are not the current response-label data. A submitted data-availability claim must wait for a complete, verified deposit.

# Companion resources for the revised ACS Photonics Article

These archives support the class-summary reanalysis, controlled 20-layer spectral-window comparison, and training-only augmented-cohort extension in **Response Complexity and Accuracy-Dependent Learning Resources in Multilayer Nanophotonic Surrogate Models**.

The original primary and separate 20-layer archived design/response CSVs remain in [v1.1.0](https://github.com/mjavani54/nanophotonic-response-manifold-learning-resources/releases/tag/v1.1.0). This release does not replace that frozen baseline. The newly generated training records use a documented reconstruction of the historical response convention; the exact original Python data-generation source remains unidentified.

# Draft release notes for the JMO candidate data

Present-study source design arrays, reconstructed response matrices, fit records, compact results, and manuscript figures for *Response Compressibility and Accuracy-Dependent Learning Requirements for Multilayer Optical Surrogates*. The source and numerical labels use εᵣ(SiO₂)=2.1316, εᵣ(TiO₂)=5.913, and field-transmission magnitude |t| with N−1 active thicknesses and a material exit medium.

The three augmented 160k NPZs and six primary CSV members match hashes recorded for the run. Four reconstructed spectral arrays match its PCA diagnostics. The primary and 200k reconstructed ZIP containers have different hashes from the originally recorded containers, which were not available for direct byte comparison.

# Suggested manuscript data/code availability statement

Stored design matrices, a Python reconstruction of the documented response convention, analysis scripts, frozen summary outputs, and selected validation fixtures are available in the accompanying GitHub repository. The author reports that the analyzed labels were generated using Python, but the specific original Python script is not identified in the public materials. The exact archived response CSVs used for the reported analyses are not yet public. Recalculation from stored rounded designs can differ numerically from those archived responses. Exact numerical reproduction of the reported analyses requires release of the archived response matrices.
